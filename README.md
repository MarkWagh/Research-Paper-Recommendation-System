# Research Paper Recommendation System (OGB `ogbn-arxiv`)

This project recommends research papers to a researcher based on the papers they have already read. It combines **paper content** (titles and abstracts) with the **citation graph**. We compare popularity, content-only and graph-only baselines with two hybrids: validation-tuned score fusion, and an inductive GraphSAGE GNN that uses text embeddings as node features. Everything is evaluated in a strictly time-aware, leakage-tested, full-ranking setting using Recall@K, NDCG@K and MRR.

**Report:** [`report/Project_Report.html`](report/Project_Report.html) is the submission. It is an executed notebook with code, outputs, figures and discussion; its source is `report/Project_Report.ipynb`, generated by `report/build_report.py`.

## Results summary (test set: 5,000 queries from 2019)

| Family | Model | Recall@20 | NDCG@20 | MRR | Recall@50 |
|---|---|---|---|---|---|
| Popularity | Popularity | 0.085 | 0.084 | 0.197 | 0.112 |
| Content | TF-IDF (own + history) | 0.216 | 0.180 | 0.323 | 0.315 |
| Content | BM25 (own + history) | 0.209 | 0.180 | 0.333 | 0.304 |
| Content | OGB features, centred (own + history) | 0.063 | 0.052 | 0.113 | 0.100 |
| Content | MiniLM (own + history) | 0.213 | 0.176 | 0.318 | 0.319 |
| Graph | Co-citation + coupling | 0.259 | 0.225 | 0.395 | 0.364 |
| Graph | Personalized PageRank | 0.351 | 0.285 | 0.431 | 0.505 |
| Graph | node2vec (3 seeds) | 0.161 ± 0.001 | 0.131 ± 0.003 | 0.241 ± 0.009 | 0.241 ± 0.002 |
| Hybrid | GNN: directional GraphSAGE on MiniLM features (3 seeds) | 0.193 ± 0.003 | 0.151 ± 0.003 | 0.256 ± 0.003 | 0.302 ± 0.004 |
| Hybrid | **Fusion: MiniLM + PPR** | 0.395 | 0.330 | 0.501 | 0.547 |
| Hybrid | **Fusion: MiniLM + PPR + popularity** | **0.401** | **0.338** | **0.517** | **0.549** |

Trained models (node2vec, GNN) show mean ± std over 3 seeds. Every hyper-parameter and fusion weight was chosen on the 2018 validation queries. Full tables are in `results/tables/main_test.md` and `results/tables/main_val.md`.

**Key findings**
- Text beats popularity by about 2×; TF-IDF and BM25 are as strong as MiniLM sentence embeddings. The provided 128-d OGB features are weak for retrieval.
- The citation graph is the strongest single signal: Personalized PageRank is the best non-hybrid model, and simple co-citation beats node2vec.
- **Fusing MiniLM text similarity with PPR is the best model overall**, but only with rank-based (log-rank) normalisation. With z-score normalisation, fusion is worse than PPR alone.
- The GNN learns a useful hybrid signal (better than node2vec, close to the text models) but does not beat PPR on its own. As a fusion component it matched the best fusion on validation; it has not been evaluated on test.

## Task definition

- A **query** is a paper P with ≥ `min_refs` (5) *eligible* references, i.e. in-dataset papers published strictly before P.
- P's eligible references are split (seed 0) into 50% **history**, which is revealed, and 50% **targets**, which are hidden.
- The model sees P's title/abstract plus the history and ranks **all** papers older than P, excluding P and the history.
- Queries: train ≤ 2017, **validation = 2018**, **test = 2019**. Val and test are capped at 5,000 queries each; set `split.max_val_queries=null split.max_test_queries=null` to use all of them. The split is saved once in `cache/splits/` and reused by every model.

**Leakage control** (`src/graph.py`, asserted in `tests/test_leakage.py`)
- *Training graph*: citations made by papers from ≤ 2017. node2vec and the GNN are trained on it.
- *Evaluation graph* for a split: citations made by papers older than that split's query year, **minus every outgoing edge of every val/test query**. This means no hidden target edge ever appears in any graph.
- Popularity, co-citation, PPR, node2vec and GNN neighbourhoods at evaluation time come only from these graphs.

## Setup

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pip install pyg_lib torch_scatter torch_sparse torch_cluster -f https://data.pyg.org/whl/torch-2.5.0+cpu.html
bash scripts/setup_macos_pyg.sh      # only on macOS with Homebrew Python (re-links the PyG extension wheels)
python -m pytest                     # 22 tests: metrics, leakage, models
```

The data downloads automatically into `data/` on first use: the OGB dataset plus `titleabs.tsv.gz` for raw text. Expensive artefacts (split, embeddings, node2vec, GNN weights) are cached in `cache/` and reused.

## Reproducing every table

```bash
python scripts/eda.py                                              # dataset stats + saves the split
python scripts/embed_text.py --models minilm                       # MiniLM embeddings (~15 min on Apple M4)
python scripts/run_baselines.py                                    # all baselines
python scripts/run_baselines.py --config configs/fusion.yaml       # MiniLM + PPR (+ popularity) fusion
python scripts/train_gnn.py                                        # GNN, 3 seeds
python scripts/run_baselines.py --config configs/fusion_gnn.yaml   # GNN + PPR (+ MiniLM) fusion
python scripts/run_ablations.py --parts breakdowns timemask qualitative
python scripts/make_tables.py && python scripts/make_tables.py --split val
python report/build_report.py                                      # executes and exports the report
```

Any config value can be overridden from the command line, e.g. `--set device=cpu split.history_frac=0.25`. Logs are written with timestamps to `results/logs/`.

## Environment notes

- Developed on an Apple M4 (16 GB RAM, no CUDA). Models run on CPU or the Apple GPU (MPS); everything falls back to CPU.
- `transformers` is pinned to 4.46.3 because newer releases require torch ≥ 2.6, while the PyG extension wheels target torch 2.5.
- The SPECTER2 encoder runs in fp16 with batch size 16 and an MPS memory cap. The first unconstrained run filled swap.
